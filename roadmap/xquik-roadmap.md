# Xquik Public API Roadmap

This roadmap lists current investment areas without delivery promises.

## Contract Quality

- Expand response and error examples.
- Publish more reusable schemas.
- Keep SDKs aligned with OpenAPI.

## Agent Safety

- Expand confirmation-gated actions.
- Improve retry and idempotency guidance.
- Publish richer agent discovery metadata.

## Developer Experience

- Expand workflow collections.
- Improve integration checklists.
- Add more automation platform connectors.

## Operations

- Expand public health signals.
- Clarify deprecation and rate-limit policies.
- Keep the changelog current.

Priorities may change after reliability or security findings.
