# Xquik API

A third-party X (Twitter) data and automation platform positioned as an X/Twitter API alternative. It covers authentication, public reads, automated writes, and webhooks across tweets, profiles, followers, replies, monitors, and media, with 23 extraction tools, HMAC-signed webhooks, and MCP support. Not affiliated with X Corp.

- **Provider:** https://xquik.com
- **Documentation:** https://docs.xquik.com
- **Base URL:** https://xquik.com/api/v1
- **Tags:** X/Twitter data, social media data, social listening, data extraction, marketing automation, webhooks, developer API, MCP, agent-native, AI agent tooling
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** yes

## APIs

- **Xquik REST API** — REST API for searching public X data, exporting tweets/replies/followers/timelines/lists/media, posting tweets, and monitoring accounts in real time. OpenAPI 3.1 with RFC 9727 discovery, pay-per-use reads, and OAuth 2.1 / API-key auth. (`https://xquik.com/api/v1`)

> All four surfaces confirmed against the provider's own developer site and well-known endpoints: REST API (base https://xquik.com/api/v1) with OpenAPI 3.1 at https://xquik.com/openapi.json; hosted MCP servers at https://xquik.com/mcp (actions, Bearer/OAuth 2.1) and https://docs.xquik.com/mcp (docs, no auth), with manifest at https://xquik.com/.well-known/mcp.json; llms.txt at both domains; and a published agent skill 'xquik' indexed at https://xquik.com/.well-known/agent-skills/index.json (SKILL.md at https://xquik.com/.well-known/agent-skills/xquik/SKILL.md), installable via 'npx skills add Xquik-dev/x-twitter-scraper'. An RFC 9727 API catalog exists at https://xquik.com/.well-known/api-catalog. Auth supports full account API keys (xq_ + 64 hex), guest keys, OAuth 2.1 PKCE (discovery at /.well-known/oauth-authorization-server), and accountless Machine Payments Protocol (MPP) pay-per-call via Tempo/USDC. No public GraphQL, AsyncAPI, or Postman collection was confirmed; the submitter's mention of Arazzo/A2A artifacts was not confirmed as published URLs (though an A2A-style agent card is referenced via /.well-known/agent-index.json).
