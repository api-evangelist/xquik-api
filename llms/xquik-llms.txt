# Xquik

> Xquik is an independent third-party service. Not affiliated with X Corp. "Twitter" and "X" are trademarks of X Corp.

Xquik helps teams search public X data, run exports, publish from connected accounts, monitor accounts or topics, run giveaway draws, and connect AI agents to X workflows.

## Core Capabilities

- Search public X posts, accounts, replies, mentions, reposts, lists, and follower data.
- Publish and manage posts from connected accounts through supported dashboard and API workflows.
- Run account or keyword monitors and deliver signed webhook events to external systems.
- Export structured results as CSV, XLSX, JSON, or Markdown for analysis and audit trails.
- Connect AI agents through MCP and use public SDKs generated from the OpenAPI schema.

## Access

- Dashboard login uses magic links.
- API keys are managed from the account dashboard.
- OAuth 2.1 is available for third-party clients.
- MCP clients should use OAuth 2.1 discovery. API-key fallback is client-specific. ChatGPT custom apps require OAuth.
- Codex error `Authorization server response missing required issuer: expected https://xquik.com`: use an Xquik API key through `bearer_token_env_var`.
- [Codex OAuth troubleshooting](https://docs.xquik.com/guides/troubleshooting#codex-oauth-issuer-validation-error): Follow the documented API-key fallback.
- [Codex upstream issue](https://github.com/openai/codex/issues/31573): Track the client compatibility fix.
- Affected Goose releases can report the same issuer error. Use Goose's documented environment-backed bearer header.
